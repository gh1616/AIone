# AIone · 极客风个人主页

简约、高格调、极客风格的个人网站，项目名 **AIone**。

## 技术栈

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- Oxlint

## 本地开发

```bash
npm install
npm run dev      # 启动开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物
```

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
